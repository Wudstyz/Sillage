# Contribuer / Contributing

🇫🇷 Merci de votre intérêt ! Ouvrez une *issue* pour proposer une idée ou signaler un problème, puis une *pull request* pour proposer un changement. Le français et l'anglais sont acceptés.

🇬🇧 Thanks for your interest! Open an issue to suggest an idea or report a problem, then a pull request to propose a change. French and English are both welcome.

En contribuant, vous acceptez que votre code soit publié sous licence MIT. / By contributing, you agree your code is released under the MIT license.
