# Notices tierces / Third-party notices

**Sillage** n'embarque aucune bibliothèque tierce : il n'utilise que les frameworks fournis par macOS
(Swift, SwiftUI, AppKit, Foundation, CoreGraphics), soumis aux conditions d'Apple.
La seule dépendance de test est XCTest (fourni avec Xcode).

*Sillage bundles no third-party library: it only uses frameworks shipped with macOS (Swift, SwiftUI, AppKit,
Foundation, CoreGraphics), under Apple's terms. The only test dependency is XCTest (shipped with Xcode).*
